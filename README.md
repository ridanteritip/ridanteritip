# 💫 About Me:
<br>Saya Rizki Ramadan, seorang praktisi teknologi yang menggabungkan keahlian software engineering dan eksekusi hardware. Memiliki fokus pada arsitektur server (Linux/NAT VPS), pengembangan backend JS, otomatisasi IoT, hingga perakitan hardware dan soldering. Dengan pendekatan kerja yang praktis, analitis terhadap peluang finansial, serta pemahaman komunikasi visual, saya siap mengeksekusi proyek teknis yang solid dan terotomatisasi.
